**مملكة البحرين - مدرسة أحمد الفاتح الإعدادية للبنين**

## 1. بيانات الحسابات الأولية للتجربة والاختبار

تم تجهيز النظام بالحسابات الرسمية المطلوبة مع شريط تعبئة سريع في نافذة تسجيل الدخول:

| الدور | الاسم الكامل | اسم المستخدم | كلمة المرور للتجربة | الصلاحيات الأساسية |
| :--- | :--- | :--- | :--- | :--- |
| **الإدارة** | مدير المدرسة | `المدير` | `00973` | متابعة المؤشرات، نسب الحضور، سجلات الانضباط، والتوجيه الإشرافي |
| **القائد 1** | القائد باسل حسن | `باسل` | `001` | الإدارة الكاملة للفرقة، اعتماد النقاط، البت في الحرمان، الفعاليات، الاستيراد |
| **القائد 2** | القائد محمد علي | `محمد` | `002` | الصلاحيات الكاملة لقيادة الفرقة، منح الشارات، وإصدار الشهادات |
| **المعلم** | أ. سلمان البنعلي | `salman` | `123456` | رصد التقييمات الإيجابية (1-5)، تسجيل الخصومات، ورفع طلبات الحرمان |
| **كشاف** | أحمد سلمان البلوشي | `scout_ahmed` | `123456` | استعراض الرصيد والشارات والشهادات، رفع الصورة بالبدلة الكشفية |

## 2. الأنظمة واللوحات الخمس

### أ. الصفحة الرئيسية
- تشتمل على شعار وزارة التربية والتعليم في مملكة البحرين، وشعار كشافة البحرين، واسم الفرقة وشعارها «كُن مستعداً».
- أزرار مباشرة للدخول إلى الأنظمة الخمسة: (الإدارة، القائد، المعلم، كشاف، ولي أمر).
- إحصائيات حية بعدد الكشافين المعتمدين، المعلمين المشاركين، والفعاليات.
- شريط الأخبار والإعلانات المعتمدة من القائد.
- بطاقة خاصة بشاشة التميز «نجوم الفرقة».

### ب. شاشة التميز «نجوم فرقة فتيان أحمد الفاتح الكشفية»
- تعرض المراكز الثلاثة الأولى (الذهب، الفضة، البرونز).
- الترتيب مبني حصرياً على النقاط المعتمدة بعد خصم المخالفات.
- لا تظهر الصورة الشخصية للكشاف إلا إذا كانت معتمدة بالزي الكشفي الرسمي.
- مؤثرات احتفالية كشفية بالقصاصات الذهبية (Confetti).

### ج. لوحة المعلم (إنجاز سريع وسلس لأكثر من 50 معلماً)
- حفظ الصف الدراسي المختار في الذاكرة لتسهيل التقييم اليومي.
- تقييم إيجابي من 1 إلى 5 نقاط مع عبارات تعزيز تربوية («استمر يا بطل!»، «وحش، إنجاز مميز!»...).
- تسجيل الخصومات للمخالفات وتوجيه تربوي للكشاف (تخضع لمراجعة القائد).
- رفع طلب حرمان من الأنشطة للمخالفات المتكررة باختيار المدة (أسبوعان، شهر، شهران، فصل كامل...).
- إرسال بلاغات وملاحظات عاجلة لقيادة الفرقة.

### د. لوحة الكشاف
- رصيد النقاط الصافي المعتمد، سجل النقاط الإيجابية، وسجل الخصومات.
- نموذج رفع الصورة الشخصية الرسمية مع التنبيه النصي الصارم بعدم النشر قبل موافقة القائد.
- معرض الشارات والأوسمة المكتسبة.
- شهادات التقدير القابلة للطباعة والمعاينة فوراً بنسق A4.
- رسائل التشجيع الواردة من المعلمين وأولياء الأمور.

### هـ. لوحة ولي الأمر
- متابعة الابن أو التبديل بين عدة أبناء إن وجدوا.
- استعراض السلوك والانضباط المعتمد دون درجات تحصيل دراسي أكاديمي.
- إرسال رسائل تشجيعية فورية تظهر في حساب الابن.
- إرسال استفسار خاص وسري لقيادة الفرقة.

### و. لوحة الإدارة المدرسية
- مؤشرات أداء الفرقة، توزيع النقاط حسب الصفوف الإعدادية (الأول، الثاني، الثالث إعدادي).
- أكثر السلوكيات الإيجابية تكراراً.
- الإشراف على طلبات الحرمان والبلاغات دون تعديل النقاط المسجلة دون تفويض.

### ز. لوحة القائد (مركز القيادة والتحكم)
- شاشة نظرة عامة شاملة لمؤشرات الفرقة.
- صندوق مراجعة واعتماد النقاط مع إمكانية القبول، الرفض، أو التصحيح الموثق.
- إدارة طلبات الحرمان والبت فيها وتحديد تاريخ انتهائها التلقائي.
- مراجعة الصور الشخصية المرفوعة للكشافين واعتمادها أو رفضها مع بيان السبب.
- إدارة الفعاليات الداخلية والخارجية ورصد كشوف الحضور والغياب.
- نظام استيراد Excel للكشافين والمعلمين مع تنزيل القالب والتحقق من التكرارات قبل الحفظ.
- سجل تدقيق غير قابل للتعديل يوثق كافة الإجراءات الحساسة بالوقت واسم المستخدم.
- تصدير نسخة احتياطية فورية (JSON) واستعادة النسخ السابقة.

## 3. طريقة التشغيل المحلي

1. **المتطلبات الأساسية:**
   - تثبيت Node.js الإصدار 20 أو 22+.
2. **تثبيت الاعتماديات:**
   ```bash
   npm install
   ```
3. **بدء الخادم في بيئة التطوير:**
   ```bash
   npm run dev
   ```
   يعمل الخادم على المنفذ `3000` على الرابط: `http://localhost:3000`.

4. **بناء النسخة النهائية للإنتاج:**
   ```bash
   npm run build
   ```

5. **تشغيل نسخة الإنتاج:**
   ```bash
   npm run start
   ```

## 4. استيراد الكشافين والمعلمين عبر Excel

1. توجه إلى لوحة القائد واختر **استيراد Excel**.
2. اضغط على **تنزيل القالب (.xlsx)**.
3. قم بتعبئة بيانات الطلبة (الاسم، الرقم الشخصي، الصف، الشعبة، اسم الطليعة).
4. ارفع الملف، وسيقوم النظام بفحص كل صف واكتشاف أي رقم شخصي مكرر أو بيانات ناقصة قبل الاعتماد.
5. انقر على **تأكيد الاستيراد** لإنشاء الحسابات وسجلات الكشافين دفعة واحدة.
